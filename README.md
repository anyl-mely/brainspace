# 🧠 BrainSpace – Your Personal Learning Ecosystem

> *"Learn Smarter. Think Deeper. Grow Further."*

**BrainSpace** là hệ sinh thái học tập cá nhân hóa kết hợp giữa **Learning Management** (Quản lý lộ trình học tập) và **Evidence-based Learning Science** (Khoa học học tập dựa trên bằng chứng nghiên cứu như *Active Recall, Spaced Repetition, Feynman Technique, Scaffolding*).

## 🏗️ Kiến trúc & Công nghệ định hướng (Tech Stack)
- **Frontend:** HTML5, CSS3, JavaScript ES6+, React, TypeScript, Tailwind CSS, Vite
- **Backend:** Node.js, Express.js, TypeScript, Zod Validation
- **Database:** PostgreSQL, Prisma ORM
- **Security & AI:** JWT + HttpOnly Cookie, DOMPurify, CORS, Rate Limiting, LLM API Tutor
- **DevOps:** Git, GitHub Actions, Docker & Docker Compose
